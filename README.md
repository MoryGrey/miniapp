# Такси Престиж - Telegram Бот

Telegram бот для автоматической отправки заказов такси в группу водителей.

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Создайте Telegram бота:
   - Напишите @BotFather в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Сохраните полученный токен

3. Получите ID группы водителей:
   - Добавьте бота в группу водителей
   - Отправьте в группу команду `/start`
   - Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
   - Найдите `"chat":{"id":-XXXXXXXXX}` - это ID группы

4. Настройте конфигурацию:
   - Откройте `bot.js`
   - Замените `YOUR_BOT_TOKEN_HERE` на ваш токен бота
   - Замените `YOUR_GROUP_ID_HERE` на ID группы водителей

## Запуск

```bash
npm start
```

Бот будет работать на порту 3000.

## Функции

- **Отправка заказов**: Каждый новый заказ автоматически отправляется в группу водителей
- **Кнопка "Принять заказ"**: Водители могут нажать кнопку для принятия заказа
- **Уведомления**: Время заказа и принятия заказа
- **Детское кресло**: Отображение необходимости детского кресла

## API Endpoints

- `POST /new-order` - Отправка нового заказа
- `POST /accept-order` - Принятие заказа водителем
